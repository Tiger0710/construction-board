工事予定表の使い方

ブラウザで工事の予定を入力すると、事務所の大画面に表示されます

1. この画面でできること

担当している工事を月ごとのガント表に登録し、日ごとに昼・夜の作業内容を入力します。

入力して「保存」を押した内容が、事務所の大画面（サイネージ）に本日・明日の予定として表示されます。

使うのはブラウザだけです。Excelファイルのやり取りはありません。

2. はじめに: 会社と担当者を選ぶ

入力画面を開くと、最初に「入力担当者を選んでください」という画面が出ます。

会社が3列に並び、その下に担当者のボタンがあります。

会社担当者のボタン
HSJ手島 / 森_吉村 / 谷口 / 河邊
コーワシステム東京 / 大阪
光洋エンジニアリング佐藤 / 森 / 神邊 / 猪股 / 日向野

ボタンの右側には「データあり」または「新規」と出ます。まだ一度も入力していない場合は「新規」です。

次回から早く開く: 担当者を選ぶと、アドレスの末尾が #担当者/年月（例: #手島/2609）に変わります。この状態でブラウザのお気に入りに登録しておくと、次回は担当者を選ばずに自分の画面が開きます。

4. 案件を追加する

「+ 案件追加」を押すと入力欄が開きます。

欄書く内容
客先発注元の会社名（必須）
工事件名工事の名前（必須）
現場担当者自社の現場担当者
安品担当者安全品質の担当者
協力会社名協力会社の名前
協力会社担当者協力会社側の担当者
開始日工事の開始日（必須）
終了日工事の終了日（必須。開始日以降）

「基本の作業時間」で昼・夜を選べます。未入力の日はこの設定で表示され、日ごとに昼夜や休みを変更できます。既存案件で設定がないものは昼として扱います。

入力したら「保存」を押します。表に新しい行が追加されます。月をまたぐ工事は、開始日から実際の終了日までを1つの案件として登録します。翌月に同じ案件を追加する必要はありません。

「初期値」の表示: 森_吉村と谷口では、客先・現場担当者・安品担当者にあらかじめ値が入ります。欄の名前の横に「初期値」と出ます。違う場合はそのまま書き換えられます。
土日について: 「土日の扱い」で「土日は休み」または「土日も稼働」を選びます。稼働する場合は「基本の作業時間」の昼・夜を使います。日別に入力した設定は優先されます。

5. 日ごとの内容を入れる

工事期間内のセル（灰色の休みの日も含む）をクリックすると、その日の入力画面が開きます。

  1. 昼の工事 のチェックを入れる／外す
    外すとその日は休み（灰色）になり、大画面にも出ません
  2. 工事内容 にその日の作業を書く
    ここに書いた内容が大画面の「作業内容」に出ます
  3. 重点工事 を「有」にすると、重点内容 を書けます
    表のセルに赤い点が付き、大画面では重点作業として目立ちます
  4. 夜も作業する日は 夜間工事 にチェックを入れる
    夜の工事内容・重点工事の欄が出ます
担当者変更: 「担当者変更」を開くと、その日だけ現場・安品・協力担当を変えられます。空欄のままなら案件に登録した担当者が使われます。
前日からコピー: 前の日と同じ内容のときは「前日からコピー」を押すと、昼夜・工事内容・重点・担当者がまとめて入ります。前の日にデータがないときは押せません。

上部の ◀ ▶ で、同じ案件の前の日・次の日に移動できます。工事の期間外には移動しません。

6. 案件を編集・削除する

表のいちばん左にある鉛筆ボタンを押すと「案件編集」が開きます。内容を直して「保存」を押します。

「基本の作業時間」を変更すると、未入力の日に適用されます。すでに日ごとに設定した昼夜・休み・作業内容は変更されません。

「削除」を押すと確認が出ます。案件と、その案件の日ごとの入力もいっしょに消えます。

削除は全期間に適用: 月をまたぐ案件も1つの案件として保存されます。特定の月だけ休みにしたいときは、案件を削除せず、その日の日次入力で昼・夜をオフにしてください。

月をまたぐ工事の入力

既存の月別データは初回にまとめて整理し、今後は同じ工事を継続して使います。翌月分を別の案件として追加する必要はありません。期間が延びるときは、既存案件の終了日を変更してください。

期間を延ばしたとき: 新しく増えた土日にも「土日の扱い」の設定を適用します。すでに入力済みの日はそのままです。翌月以降の工事も、この案件の終了日を延ばして入力してください。
土日設定を切り替える: 案件編集の「土日の扱い」を変更して保存します。この設定で自動作成した休みは、稼働へ切り替えられます。日別に入力した作業・休みや、以前からある休みは保持します。以前からある休みを変更するときは、その日のセルで昼・夜を選んでください。

7. 保存する

入力が終わったら、ヘッダー2行目の右側にある「保存」を押します。

変更がないときは「保存」は押せない状態になっています。何か変更すると押せるようになります。

保存しないと反映されません: 案件の追加や日ごとの入力は、「保存」を押すまで自分の画面の中だけの状態です。月の切り替えでは入力を保持します。同じ担当者の複数月分を編集してから、まとめて保存できます。保存せずにページを閉じる、または担当者を切り替えると、未保存の変更を確認します。

保存に成功すると「保存しました」と数秒表示されます。

他の人と同時に保存したとき: 「データが他のユーザーによって更新されています。ページをリロードしてください。」と赤字で出ることがあります。この場合は保存されていません。ページを再読み込みして最新の状態にしてから、入力し直して保存してください。

8. サイネージ（大画面の表示）

大画面には、全担当者の本日・明日の工事予定が表示されます。ヘッダーの「サイネージ表示」からも同じ画面を開けます。

項目内容
ページ送り30秒ごとに切り替わります。HSJ → コーワ → 光洋の順に、各社の本日・明日の全ページを表示します。予定のない会社・日付はスキップします
会社の区別会社ごとにページを分け、左上に会社名を表示します。未登録の担当者は「その他」として最後に表示します。本日・明日の稼働件数とフッターは全社合計です
表示される列会社・客先・工事件名・現場・安品・協力会社・担当・作業内容・昼/夜・重点作業
データの更新5分ごとに自動で読み直します。保存してから反映まで最大5分かかります
すぐに反映したいとき: サイネージの画面でキーボードの r キーを押すと、その場で最新のデータを読み直します。◀ ▶ キーでページ送り、n キーで本日と明日の切り替えができます。

9. よくある質問

担当者が増えたときは
最初の選択画面に出る担当者はあらかじめ決まっています。一覧にない担当者を追加するには設定の変更が必要なので、管理者（REVA 加藤）に連絡してください。
自分が入れたはずの案件が表示されない
まず、ヘッダーの担当者タブが自分になっているか、◀ ▶ の月が合っているかを確認してください。案件の開始日から終了日まで、該当する各月に同じ案件が表示されます。長期工事も月ごとに作り直す必要はありません。
土日に作業するとき
その日のセルをクリックして「昼の工事」または「夜間工事」にチェックを入れてください。灰色から色付きに変わります。
月をまたぐ工事はどうなる
今月・来月にまたがる案件は、隣の月のデータからも読み込まれ、表の下のほうに薄い行として「○月」のバッジ付きで表示されます。この行のセルをクリックすると、その案件が登録されている月に切り替わります。切り替えた月で内容を編集してください。
間違えて入力した
保存前なら、ページを再読み込みすると入力前の状態に戻ります（確認が出ます）。保存した後は、正しい内容を入力し直してもう一度保存してください。案件ごと消す場合は鉛筆ボタンから「削除」です。
